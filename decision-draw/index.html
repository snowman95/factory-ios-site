결정 뽑기

개발 중인 독립 iOS 앱입니다. 아직 TestFlight나 App Store에 배포하지 않았습니다. 아래는 준비 중인 기능과 정보 처리 안내이며 실제 배포 전에 갱신합니다.

후보를 선택하고, 순서를 정하고, 팀을 나눠 마지막 결과를 기기에 보관하세요.

준비 중인 기능

  • 2~100개 후보 중 선택한 수만큼 중복 없이 뽑기
  • 입력한 모든 후보의 순서 정하기
  • 인원 차이가 최대 1명인 팀 나누기
  • 같은 이름 확인과 직접 구별한 후보 목록
  • 마지막 결과의 기기 저장과 다시 열기
  • 이름 포함 여부를 선택한 결과·앱 안내 링크 복사
  • 이 앱의 저장 결과와 후보 목록 초기화

기본 뽑기는 무료입니다. 결과를 본 뒤 입력을 바꾸더라도 저장한 결과는 생성 당시의 후보 목록을 기준으로 표시합니다.

기록 공유

기본 복사에는 이름 대신 입력 순서의 후보 번호를 넣습니다. 실제 이름을 포함하려면 별도로 선택하세요. 공유할 대상과 내용을 직접 확인해 주세요.
