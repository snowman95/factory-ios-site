현재 등록된 내부 테스터에게 제공한 버전은 TestFlight 1.0.0(빌드 7)입니다. 정식 배포용 빌드 8은 준비 중이며 아직 제공·심사 완료를 뜻하지 않습니다. App Store 공개 출시는 준비 중입니다.

개인정보 처리 안내

이 안내는 지원금 도우미 독립 iOS 앱에 적용됩니다. 기존 토스 미니앱에는 해당 서비스의 별도 안내가 적용됩니다. 운영 및 문의는 이메일로 문의하기로 받습니다.

1. 기기에서 사용하는 정보

최대 5개의 조건 이름과 나이대·지역·가구유형·소득 구간, 선택한 관심 제도, 서류·단계 체크, 직접 기록한 신청 진행 상태와 변경 시각, 내가 정한 확인 예정일, 준비 메모를 이 기기에 저장합니다. 장려금·연금 안내 화면에 입력하는 소득·재산은 화면의 참고 비교에 사용하며 운영자 서버로 신청서나 준비 기록을 보내지 않습니다. 주민등록번호·계좌번호·정부 서비스 로그인 정보는 입력받지 않습니다. 조건 이름에 실명을 넣거나 메모에 개인 식별 정보를 적지 마세요.

신청 기록 요약을 공유·복사하기 전에 내용을 확인할 수 있습니다. 기본 요약에는 제도 이름·내가 기록한 상태·체크 개수와 앱 안내 링크만 들어갑니다. 조건 구간은 직접 포함 옵션을 켤 때만 추가되며, 조건 이름·준비 메모·확인 예정일은 이 요약에 포함하지 않습니다. 공유를 선택한 경우 본인이 선택한 앱과 대상의 처리 방식이 적용됩니다.

위의 기기 기록은 해당 iOS 앱의 로컬 저장 공간에서 사용합니다. 운영자가 이 기록을 받아 계정별로 보관하는 회원가입·클라우드 동기화 기능은 제공하지 않습니다. 별도의 운영자 행동 분석 SDK는 연결되어 있지 않습니다. 광고 SDK를 적용하는 새 버전의 처리는 아래 별도 항목과 구분해 확인해 주세요.

2. 네트워크 및 외부 서비스

공개 제도 및 통계 참고 자료는 앱에 포함되어 제공됩니다. 사용자가 공식 안내·신청 링크를 선택하면 해당 기관의 사이트와 정책이 적용됩니다. 앱의 조건 입력을 정부기관에 대신 제출하지 않습니다.

외부 자료 요청이나 링크 방문 시 인터넷 통신에 필요한 IP 주소·접속 시각·요청 정보가 해당 호스팅·지도·웹 서비스에서 처리될 수 있습니다. 운영자는 기기 기록을 광고 사업자에게 판매하지 않습니다. 공유를 선택한 경우 본인이 선택한 앱·대상에 공유 내용이 전달됩니다.

이 지원·개인정보 웹사이트는 GitHub Pages에 게시되어 있습니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관합니다. GitHub Pages의 데이터 처리 안내와 GitHub 개인정보 안내를 확인해 주세요.

3. 보관 및 삭제

저장한 제도는 개별 삭제할 수 있고, 조건을 삭제하면 그 조건에 연결된 신청 준비 기록도 함께 지워집니다. 전체 초기화는 확인 후 조건과 신청 준비 기록을 이 기기에서 삭제합니다. 기기에만 저장되므로 운영자가 원격 복구할 수 없습니다. 앱 삭제나 기기 저장 공간 삭제 시 자료가 사라질 수 있으며 앱 정리(Offload)는 자료가 남을 수 있습니다. iOS 백업·복원은 본인의 기기·계정 설정에서 관리하세요.

4. 문의를 보낸 경우

사용자가 이메일로 문의하면 회신 이메일 주소와 본인이 제공한 문의 내용·첨부파일을 문제 확인과 답변에 사용합니다. 필요한 범위만 보내 주세요. 문의 처리가 완료되면 불필요한 내용은 삭제합니다. 문의 내용의 열람·정정·삭제 요청도 같은 이메일로 받을 수 있습니다. 법령상 보관이 필요한 경우 해당 범위와 기간에 한정해 보관합니다.

회원가입이나 실명 등록을 요구하지 않습니다. 앱의 기능에 필요하지 않은 신분증·주민등록번호·의료서류 등의 민감한 정보를 문의에 포함하지 마세요.
