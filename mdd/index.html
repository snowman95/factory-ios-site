MDD 계산기

MDD 계산기는 주요 지수·ETF·주식·코인의 최대낙폭(MDD)과 지금 고점에서 얼마나 내려왔는지를 보여주는 앱입니다. 기간별·역사적 하락장별 MDD와 회복 기간, 여러 자산 비교, 자산을 섞은 포트폴리오의 MDD, 손실 회복 계산기, 직접 붙여넣은 가격·평가금액의 MDD, 레버리지 가상 MDD를 계산하고, 정한 하락률에 도달하면 알려 주는 MDD 알림을 제공합니다.

데이터 기준

가격은 앱에 포함된 일별 종가(배당·분할 반영 수정종가, 지수는 종가) 기준이며 앱 화면에 기준일을 표시합니다. 장중 가격이나 실시간 시세가 아닙니다. 앱 업데이트 시 데이터를 갱신합니다.

유의 사항

모든 결과는 과거 데이터로 계산한 참고 자료이며 투자 권유, 종목 추천, 미래 수익·손실의 예측이 아닙니다. 세금·수수료·환전 비용은 반영하지 않습니다. 레버리지 결과는 단순 모델에 의한 가상 수치입니다. 이 앱은 거래소·증권사·지수 사업자와 제휴하거나 인증받은 앱이 아닙니다.
