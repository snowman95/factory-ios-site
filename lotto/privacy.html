개인정보 처리 안내

이 안내는 로또 명당 찾기 독립 iOS 앱에 적용됩니다. 기존 토스 미니앱에는 해당 서비스의 별도 안내가 적용됩니다. 운영 및 문의는 이메일로 문의하기로 받습니다.

1. 기기에서 사용하는 정보

사용자가 저장한 로또 번호 조합과 저장 시각을 기기에 보관합니다. 위치 기능이 제공되는 빌드에서 현재 위치는 사용자가 버튼을 누르고 허용한 경우에만 앱 사용 중 한 번씩 읽습니다. 지도 안의 내 위치로 버튼도 누를 때마다 새 위치를 한 번 요청해 중심을 이동하며, 자동·실시간 추적은 하지 않습니다. 이 새 위치는 지도 화면에서만 사용하며 목록 거리는 내 주변 버튼으로 별도 갱신합니다. 권한을 거부한 경우 사용자가 재시도하면 설정에서 허용하는 방법을 안내하고, 설정은 사용자가 선택한 경우에만 엽니다. 위도·경도·정확도는 가까운 매장의 직선거리 계산·정렬과 지도 표시를 위해 메모리에서 사용하며 기기에 위치 이력으로 저장하거나 운영자 서버에 보내지 않습니다. 위치 사용 해제로 화면의 좌표를 지울 수 있습니다. 백그라운드 위치 추적은 하지 않습니다. 위치를 거부해도 수동 목록 검색과 번호 기능을 사용할 수 있습니다. 구매 내역이나 결제정보는 수집하지 않습니다.

위의 기기 기록은 해당 iOS 앱의 로컬 저장 공간에서 사용합니다. 운영자가 이 기록을 받아 계정별로 보관하는 회원가입·클라우드 동기화 기능은 제공하지 않습니다. 별도의 운영자 행동 분석 SDK는 연결되어 있지 않습니다. 광고 SDK를 적용하는 새 버전의 처리는 아래 별도 항목과 구분해 확인해 주세요.

2. 네트워크 및 외부 서비스

회차·판매점 공개 자료는 Supabase 데이터 호스팅 서비스에서 전체 목록을 조회하고 이름·주소·지역 검색과 거리 계산은 기기에서 처리합니다. 검색어와 현재 좌표를 운영자 데이터베이스 조회 조건으로 전송하지 않습니다. 사용자가 지도 버튼을 선택하면 iOS의 Apple MapKit 지도로 판매점과 선택적으로 내 위치를 표시합니다. 지도 서비스 통신에는 지도 화면 범위·좌표가 반영될 수 있으며 Apple의 개인정보 정책이 적용됩니다. 선택한 매장의 외부 지도 버튼을 누르면 공개 매장 이름·좌표 또는 공개 주소를 HTTPS 링크로 카카오맵에 전달하며 이후 카카오의 정책이 적용됩니다. 이 외부 매장 링크에는 사용자의 현재 좌표를 추가하지 않습니다.

외부 자료 요청이나 링크 방문 시 인터넷 통신에 필요한 IP 주소·접속 시각·요청 정보가 해당 호스팅·지도·웹 서비스에서 처리될 수 있습니다. 운영자는 기기 기록을 광고 사업자에게 판매하지 않습니다. 공유를 선택한 경우 본인이 선택한 앱·대상에 공유 내용이 전달됩니다.

이 지원·개인정보 웹사이트는 GitHub Pages에 게시되어 있습니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관합니다. GitHub Pages의 데이터 처리 안내와 GitHub 개인정보 안내를 확인해 주세요.

  • Supabase 개인정보 안내 (공개 데이터 연결 기능)
  • 카카오 개인정보 처리방침 (선택한 판매점의 외부 카카오맵 링크)
  • Apple 개인정보 안내: TestFlight 및 iOS의 진단·피드백·기기 백업은 Apple 서비스와 사용자의 설정에 따라 처리됩니다.

3. 보관 및 삭제

기기 기록은 사용자가 삭제·해제하거나 전체 앱 데이터를 삭제할 때까지 기기에 남을 수 있습니다. 앱 정리는 데이터 삭제와 다릅니다. iOS 백업에서의 보관·복원은 사용자의 Apple 계정 및 백업 설정에 따릅니다. 기기에만 있는 기록의 열람·수정·삭제는 앱 화면 또는 iOS 설정에서 직접 관리할 수 있습니다.

4. 문의를 보낸 경우

사용자가 이메일로 문의하면 회신 이메일 주소와 본인이 제공한 문의 내용·첨부파일을 문제 확인과 답변에 사용합니다. 필요한 범위만 보내 주세요. 문의 처리가 완료되면 불필요한 내용은 삭제합니다. 문의 내용의 열람·정정·삭제 요청도 같은 이메일로 받을 수 있습니다. 법령상 보관이 필요한 경우 해당 범위와 기간에 한정해 보관합니다.

5. 어린이 및 민감한 정보

회원가입이나 실명 등록을 요구하지 않습니다. 앱의 기능에 필요하지 않은 신분증·주민등록번호·의료서류 등의 민감한 정보를 문의에 포함하지 마세요.

현재 빌드 8 등 이전 버전의 광고 개인정보 안내

이 항목은 이전 제공 버전의 정책이며 다음 빌드 9 변경 내용은 이어지는 별도 항목을 확인해 주세요.

아래 광고 처리 안내는 배너와 선택형 보상 광고를 제공하는 앱 버전에 적용됩니다. 설치한 버전에 따라 광고 제공 여부와 권한 안내 화면이 다를 수 있습니다. 광고가 없는 이전 버전이나 아직 배포되지 않은 앱에 광고가 제공된다는 뜻은 아닙니다.

광고가 적용되는 버전은 Google Mobile Ads SDK를 통해 광고를 요청합니다. Google의 SDK 안내에 따르면 IP 주소를 통한 대략적인 위치, 사용 가능한 기기·앱 관련 식별자, 광고 노출·클릭·영상 상호작용, 앱 성능 및 충돌 정보 등이 광고 제공·측정·부정사용 방지와 진단을 위해 처리될 수 있습니다. 별도의 운영자 행동 분석 SDK가 없더라도 광고 SDK 자체의 측정·진단 처리는 있습니다.

광고가 적용되는 버전에서는 설치한 버전에 따라 최초 ‘광고용 정보 공유 안내’의 ‘계속’을 누르거나 ‘광고 동의 설정’에서 iOS 앱 추적 투명성(ATT) 권한 요청으로 이어집니다. iOS 권한이 아직 미결정일 때만 시스템 요청을 엽니다. 이미 허용·거부·제한 상태이면 다시 요청하지 않습니다. 안내의 ‘계속’은 추적 허용에 동의하는 버튼이 아니며 다음 iOS 화면에서 허용 여부를 선택합니다. 앱이 활성 상태이고 iOS에서 추적을 허용했으며 Google 동의 관리 도구(UMP)도 광고 요청을 허용한 경우에만 광고 SDK를 초기화하고 배너·보상 광고를 요청합니다. 거부·제한·미결정 상태이거나 동의 확인에 실패하면 광고를 요청하지 않으며 기본 기능과 같은 추가 콘텐츠의 무료 생성 경로를 계속 이용할 수 있습니다. iOS 설정에서 이 앱의 추적 권한을 변경할 수 있으며, 다시 앱으로 돌아오면 상태를 확인하고 허용이 철회된 경우 표시 중인 배너를 제거하고 광고 요청을 중단합니다. UMP의 지역별 개인정보 선택과 iOS 추적 권한은 별개의 설정입니다.

광고 동의 후에도 비개인화 광고 요청과 Google의 게시자 자사 식별자 비활성화를 유지합니다. 비개인화 요청은 광고 SDK의 모든 정보 수집이나 외부 입찰 광고의 측정 처리가 없다는 뜻은 아닙니다. 광고 제공에 참여하는 Google 및 외부 광고 사업자는 기기 식별자·광고 상호작용 등의 정보를 광고 제공·측정에 사용할 수 있으며, iOS 추적 권한은 다른 회사의 자료와 연결하는 광고 측정 처리에 대한 허가도 포함합니다. 새 버전의 실제 SDK 설정과 App Store 개인정보 답변을 함께 확인해 주세요.

기기의 이름·생년월일·접종 기록, 소득·재산·계산 입력, ETF 관심·보유 목록, 환율 알림 토큰·설치 인증값·구독, 로또의 현재 좌표는 광고 타기팅이나 보상 광고의 사용자 식별값으로 보내지 않습니다. 기기에서 생성한 보상 결과·이용권 시각은 로컬 저장소에서 관리합니다. 사용자가 공유·복사를 선택하면 공유 내용과 앱 안내 링크가 본인이 선택한 대상에 전달됩니다.

광고 요청 전 Google 동의 관리 도구(UMP)로 상태를 확인하고, 지역과 설정에 따라 필요한 동의 화면을 제공합니다. 도구가 개인정보 선택 재설정을 요구하면 앱의 ‘광고 개인정보 설정’에서 해당 화면을 다시 열 수 있습니다. 광고를 불러오지 못하거나 선택 광고를 취소한 것을 완료로 취급하지 않습니다. 추가 카드·번호 세트는 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼도 같은 콘텐츠를 제공하며, 그 광고 경로에서만 실제 SDK 완료 콜백을 확인한 후 저장합니다. 광고 취소·실패 후에도 무료 생성 경로는 이용할 수 있습니다.

Google이 처리하는 정보의 보관·삭제 및 설정은 Google의 정책을 따르며 앱의 로컬 기록 삭제 기간과 같다고 보장하지 않습니다. 이 안내 사이트 자체에는 광고 SDK나 운영자 분석·광고 추적 스크립트를 넣지 않습니다. 문의 시 계정 비밀번호나 기기 인증값을 보내지 마세요.

  • Google 개인정보처리방침
  • Google 광고 개인정보 설정 안내

다음 빌드 9의 광고 개인정보 안내

현재 제공된 빌드 8 안내는 그대로 유지합니다. 아래는 다음 빌드 9를 실제 제공한 뒤 적용할 조건부 안내이며, 아직 설치 가능·정식 출시·새 광고 실행 성공을 뜻하지 않습니다.

처음 광고용 정보 공유 안내의 ‘계속’은 추적 허용에 동의하는 버튼이 아닙니다. iOS 권한이 미결정일 때만 시스템 선택 화면을 열며 이미 허용·거부·제한된 권한은 반복 요청하지 않습니다. 추적을 거부하거나 제한된 상태라도 앱이 활성 상태이고 별도 UMP 광고 개인정보 선택 상태가 광고 요청을 허용하면 비맞춤 배너·선택형 보상 광고를 요청할 수 있습니다. 미결정·비활성 상태 또는 권한·동의 확인 실패에는 광고를 요청하지 않습니다. 설정 변경과 활성 복귀 시 현재 상태를 다시 확인합니다.

비맞춤 광고 요청과 게시자 자사 식별자 비활성 설정을 유지합니다. 추적 허용은 혜택의 조건이나 보상이 아닙니다. 비맞춤 광고가 광고 사업자의 모든 정보 수집·측정 처리를 없애는 것은 아닙니다. 하단 ‘광고 동의 설정’과 홈의 ‘오픈소스 라이선스’는 작은 한 줄 메뉴에서 누를 때 설명·읽기 화면을 엽니다. 표시 중인 광고와 고정 메뉴 높이를 본문·시트에 예약하도록 구성하며 실제 화면 검증 완료를 이 초안만으로 보장하지 않습니다.

Google Mobile Ads SDK는 IP 주소로 추정한 대략적인 위치, 사용 가능한 기기·앱 식별자, 광고 노출·클릭·영상 상호작용과 성능·충돌·진단 정보를 광고 제공·측정·부정사용 방지와 진단을 위해 처리할 수 있습니다. 별도 운영자 행동 분석 SDK가 없더라도 광고 SDK 자체의 측정·진단 처리는 있습니다. 현재 위치·저장한 번호 기록은 광고 타기팅이나 보상 광고 사용자 식별값으로 보내지 않습니다. UMP의 지역별 개인정보 선택은 iOS 추적 권한과 별개이며 한 줄 메뉴의 광고 동의 설정에서 해당 개인정보 선택 화면을 열 수 있습니다.
