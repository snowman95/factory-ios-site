공개 앱 안내 주소

로또 명당 찾기는 공개 판매점 기록을 바탕으로 매장을 찾아보는 앱입니다. 이름·주소 검색과 지역 필터로 판매점 목록을 탐색하고, 현재 위치 버튼을 눌러 허용하면 가까운 매장을 거리순으로 살펴볼 수 있습니다. 지도는 버튼을 선택할 때 Apple 지도로 열며 판매점과 선택적으로 내 위치를 확인할 수 있습니다. 선택한 매장의 외부 카카오맵 링크도 제공합니다. 번호 조합 생성·저장과 조회된 과거 회차의 당첨 비교를 보조 기능으로 제공합니다. 자료의 기준일을 확인해 주세요. 과거 매장 기록과 생성 번호는 당첨 확률을 높이거나 당첨을 보장하지 않으며 복권 판매·결제를 하지 않습니다.

명당은 과거 공개 당첨 기록을 살펴보는 표현이며 미래 당첨 가능성을 보장하지 않습니다. 공개 결과와 기준일은 동행복권의 공식 자료로 확인하세요. 이 앱은 복권 판매·구매 대행 서비스가 아닙니다.

준비 중인 새 버전에서는 추가 카드·번호 세트도 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼을 선택해도 같은 콘텐츠가 제공되며, 그 광고 경로는 실제 SDK 완료 확인 후에만 저장합니다. 광고 취소·실패를 완료로 취급하지 않으며 무료 생성 경로는 계속 이용할 수 있습니다.

저장된 기록과 데이터

사용자가 저장한 로또 번호 조합과 저장 시각을 기기에 보관합니다. 위치 기능이 제공되는 빌드에서 현재 위치는 사용자가 버튼을 누르고 허용한 경우에만 앱 사용 중 한 번씩 읽습니다. 지도 안의 내 위치로 버튼도 누를 때마다 새 위치를 한 번 요청해 중심을 이동하며, 자동·실시간 추적은 하지 않습니다. 이 새 위치는 지도 화면에서만 사용하며 목록 거리는 내 주변 버튼으로 별도 갱신합니다. 권한을 거부한 경우 사용자가 재시도하면 설정에서 허용하는 방법을 안내하고, 설정은 사용자가 선택한 경우에만 엽니다. 위도·경도·정확도는 가까운 매장의 직선거리 계산·정렬과 지도 표시를 위해 메모리에서 사용하며 기기에 위치 이력으로 저장하거나 운영자 서버에 보내지 않습니다. 위치 사용 해제로 화면의 좌표를 지울 수 있습니다. 백그라운드 위치 추적은 하지 않습니다. 위치를 거부해도 수동 목록 검색과 번호 기능을 사용할 수 있습니다. 구매 내역이나 결제정보는 수집하지 않습니다.

앱의 삭제·해제 기능이 제공되는 항목은 해당 화면에서 직접 지울 수 있습니다. 기기 안의 전체 앱 데이터를 지우려면 iOS 설정에서 앱을 삭제해 주세요. 앱 정리(Offload)는 앱 데이터가 남을 수 있습니다. 운영자는 기기 기록을 원격으로 복구할 수 없으며, iOS 백업은 본인의 기기·계정 설정에서 관리해 주세요.
