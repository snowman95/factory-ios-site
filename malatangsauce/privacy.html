개인정보 처리 안내

이 안내는 마라탕소스레시피 독립 iOS 앱에 적용됩니다. 기존 토스 미니앱에는 해당 서비스의 별도 안내가 적용됩니다. 운영 및 문의는 이메일로 문의하기로 받습니다.

1. 기기에서 사용하는 정보

즐겨찾기 레시피 식별자 및 직접 작성한 소스 이름·재료 비율·메모를 기기에 저장합니다. 이 메모는 운영자 서버로 전송하지 않습니다.

위의 기기 기록은 해당 iOS 앱의 로컬 저장 공간에서 사용합니다. 운영자가 이 기록을 받아 계정별로 보관하는 회원가입·클라우드 동기화 기능은 제공하지 않습니다. 별도의 운영자 행동 분석 SDK는 연결되어 있지 않습니다. 광고 SDK를 적용하는 새 버전의 처리는 아래 별도 항목과 구분해 확인해 주세요.

2. 네트워크 및 외부 서비스

소스 제안과 비율은 앱에 포함됩니다. 사용자 소스 메모를 운영자에게 전송하거나 영상·SNS 정보를 조회하지 않습니다. 사용자가 공유하면 선택한 대상의 서비스 정책이 적용됩니다.

외부 자료 요청이나 링크 방문 시 인터넷 통신에 필요한 IP 주소·접속 시각·요청 정보가 해당 호스팅·지도·웹 서비스에서 처리될 수 있습니다. 운영자는 기기 기록을 광고 사업자에게 판매하지 않습니다. 공유를 선택한 경우 본인이 선택한 앱·대상에 공유 내용이 전달됩니다.

이 지원·개인정보 웹사이트는 GitHub Pages에 게시되어 있습니다. GitHub는 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관합니다. GitHub Pages의 데이터 처리 안내와 GitHub 개인정보 안내를 확인해 주세요.

  • Apple 개인정보 안내: TestFlight 및 iOS의 진단·피드백·기기 백업은 Apple 서비스와 사용자의 설정에 따라 처리됩니다.

3. 보관 및 삭제

기기 기록은 사용자가 삭제·해제하거나 전체 앱 데이터를 삭제할 때까지 기기에 남을 수 있습니다. 앱 정리는 데이터 삭제와 다릅니다. iOS 백업에서의 보관·복원은 사용자의 Apple 계정 및 백업 설정에 따릅니다. 기기에만 있는 기록의 열람·수정·삭제는 앱 화면 또는 iOS 설정에서 직접 관리할 수 있습니다.

4. 문의를 보낸 경우

사용자가 이메일로 문의하면 회신 이메일 주소와 본인이 제공한 문의 내용·첨부파일을 문제 확인과 답변에 사용합니다. 필요한 범위만 보내 주세요. 문의 처리가 완료되면 불필요한 내용은 삭제합니다. 문의 내용의 열람·정정·삭제 요청도 같은 이메일로 받을 수 있습니다. 법령상 보관이 필요한 경우 해당 범위와 기간에 한정해 보관합니다.

5. 어린이 및 민감한 정보

회원가입이나 실명 등록을 요구하지 않습니다. 앱의 기능에 필요하지 않은 신분증·주민등록번호·의료서류 등의 민감한 정보를 문의에 포함하지 마세요.

빌드 5의 광고 개인정보 안내

현재 내부 TestFlight 1.0.0(빌드 5)에 적용되는 안내입니다. App Store 공개 출시는 준비 중입니다.

최초 광고용 정보 공유 안내의 ‘계속’은 추적 허용에 동의하는 버튼이 아닙니다. iOS 권한이 미결정일 때만 다음 시스템 화면에서 선택하며 이미 허용·거부·제한된 권한은 반복 요청하지 않습니다. 추적을 거부하거나 제한된 경우에도 앱이 활성 상태이고 별도의 UMP 광고 개인정보 선택 상태가 광고 요청을 허용하면 비맞춤 배너와 선택형 보상 광고를 요청할 수 있습니다. 미결정·비활성 상태나 권한·동의 확인 실패에는 광고를 요청하지 않습니다. 설정 변경과 활성 복귀 시 현재 상태를 다시 확인합니다.

비맞춤 광고 요청과 게시자 자사 식별자 비활성 설정을 유지합니다. 추적 허용을 혜택의 조건이나 보상으로 사용하지 않습니다. 비맞춤 설정이 광고 사업자의 모든 정보 수집·측정 처리를 없애는 것은 아닙니다.

하단의 ‘광고 동의 설정’과 홈의 ‘오픈소스 라이선스’는 작은 한 줄 메뉴에서 누를 때만 설명과 읽기 화면을 엽니다. 배너가 표시될 때는 실제 광고 높이와 하단 메뉴 영역을 본문·시트에서 예약하도록 구성하며, 운영 광고 노출은 광고 공급·동의 상태·통신 환경에 따라 달라질 수 있습니다.

Google Mobile Ads SDK는 IP 주소로 추정한 대략적인 위치, 사용 가능한 기기·앱 식별자, 광고 노출·클릭·영상 상호작용과 성능·충돌·진단 정보를 광고 제공·측정·부정사용 방지와 진단을 위해 처리할 수 있습니다. 별도 운영자 행동 분석 SDK가 없어도 광고 SDK 자체의 측정·진단 처리는 있습니다. UMP의 지역별 개인정보 선택은 iOS 추적 권한과 별개의 설정입니다. 광고 개인정보 선택을 다시 확인해야 하면 한 줄 메뉴의 ‘광고 동의 설정’에서 해당 화면을 엽니다.

작업실의 계량·준비 체크·팬트리·내 비율·맛보기·장보기 기록과 기존 내 소스 메모는 기기에 보관합니다. 이 개인 기록을 운영자 서버나 광고 타기팅·보상 광고 사용자 식별값으로 보내지 않습니다. 사용자가 공유·복사를 선택한 경우 선택한 본문과 앱 안내 링크가 본인이 선택한 대상에 전달됩니다. 추가 비교 카드도 기기 저장소에서 관리하며 저장 실패를 완료로 안내하지 않습니다. 앱 삭제·백업의 처리와 운영자 문의는 위의 보관·삭제 안내를 따릅니다.

기본 레시피·즐겨찾기·내 소스 메모와 작업실의 계량·재료 준비·팬트리·직접 섞기·맛보기 기록·내 비율 저장·장보기는 무료입니다. 선택한 서로 다른 두 소스의 앱 제안 비율 비교 카드 1개를 새로 만드는 별도 버튼에서는 긴 전면 광고가 표시될 수 있음을 먼저 안내합니다. 광고 길이와 닫는 단계는 광고마다 다릅니다. 사용자가 명시적으로 선택한 광고의 실제 SDK 보상 완료 콜백 뒤에만 카드를 생성·저장하며, 저장 읽기 확인 실패를 성공으로 안내하지 않습니다. 완료 전 취소·실패·단순 광고 표시만으로 새 카드를 만들지 않습니다. 이미 받은 카드의 열람과 본문·앱 안내 링크 복사는 계속 이용할 수 있습니다. 앱 실행·탭 전환·결과·타이머로 자동 전면 광고를 띄우지 않습니다.

Google과 외부 광고 사업자의 보관·삭제 기간을 앱의 로컬 기록과 같다고 보장하지 않습니다. Google SDK 데이터 처리 안내와 Google 개인정보처리방침, Google 광고 설정 안내를 확인해 주세요. 사이트 자체의 운영자 분석·광고 추적 스크립트 미사용 안내는 유지합니다.
