# Factory iOS support site

Public support and privacy pages for seven standalone iOS apps. No FX pages or existing websites are modified.

Generated from `native/release/testflight-tools/site.cjs` and `apps.cjs` in the private Factory source repository. Icons are existing native app brand assets. Static HTML/CSS only; no analytics, ads, cookies, credentials or review phone numbers.

GitHub Pages: https://snowman95.github.io/factory-ios-site/
