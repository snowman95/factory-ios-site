# Factory iOS support site

Public support and privacy pages for seven standalone iOS apps. No FX pages or existing websites are modified.

Generated from `native/release/testflight-tools/site.cjs`, `apps.cjs` and `share-metadata.cjs` in the private Factory source repository. Original brand icons are composed into 1200×630 link preview cards. Absolute canonical, Open Graph and Twitter URLs are app-specific. Small inline JavaScript only copies the public page URL; no analytics, ads, cookies, credentials or review phone numbers. Unpublished App Store links and private TestFlight links are not exposed.

GitHub Pages: https://snowman95.github.io/factory-ios-site/
