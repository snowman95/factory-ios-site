납부일 관리 개인정보

개발 중인 독립 iOS 앱입니다. 아직 TestFlight나 App Store에 배포하지 않았으며, 현재 기기 알림 기능도 연결하지 않았습니다. 아래는 준비 중인 기능과 정보 처리 안내입니다.

적용 범위와 운영자

준비 중인 납부일 관리 독립 iOS 앱의 안내입니다. 기존 토스 미니앱에는 해당 서비스 안내가 적용됩니다. 운영 및 개인정보 문의: 이메일로 문의하기.

기기 기록

항목 이름·분류·예정 금액·매월 납부일, 월별 직접 입력한 납부일·금액을 기기 로컬 저장소에 저장합니다. 회원 계정이나 운영자 서버와 동기화하지 않으며 은행 계좌·거래 내역·자동이체 정보를 조회하지 않습니다. 기록을 직접 복사하면 해당 월의 기록과 앱 안내 링크가 클립보드에 들어가며, 다른 대상에 공유할 때 해당 대상의 정보 처리 정책이 적용됩니다.

보관·수정·삭제

앱에서 항목과 납부 기록을 수정·삭제하거나 전체 초기화할 수 있습니다. iOS 앱 정리(Offload)는 데이터 삭제와 다르며, 기기 백업·복원은 사용자의 Apple 계정 및 iOS 설정을 따릅니다. 운영자는 기기 기록을 원격으로 열람하거나 복구하지 않습니다.

기기 알림과 광고

현재 기기 알림과 광고 SDK를 이 앱에 연결하지 않았습니다. 로컬 알림을 도입한다면 별도 버튼에서 알림 권한을 요청하고, 기본 알림 내용에는 사용자가 입력한 항목 이름·금액을 표시하지 않는 방식으로 준비합니다. 실제 도입 전에 이 안내와 배포 화면을 갱신합니다.

무료 앱의 배너·선택 광고도 후속 준비 대상입니다. 광고 SDK를 도입하기 전에 이 앱의 광고 단위·지역별 동의·iOS 추적 선택과 실제 SDK 데이터 처리를 확인하고 안내를 갱신합니다. 광고 기능이 없는 현 단계의 준비 설명을 실제 광고 동작 확인으로 간주하지 않습니다.

외부 링크와 지원 사이트

지원 링크를 열면 인터넷 통신에 필요한 IP 주소·요청 정보가 외부 사이트에 전달됩니다. 이 사이트는 GitHub Pages에 게시되며 GitHub는 보안을 위해 방문자의 IP 주소를 처리합니다. 운영자 분석·광고 추적 스크립트는 없습니다.
