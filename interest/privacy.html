회원가입이나 로그인이 없습니다. 은행·증권 계좌에 연결하지 않으며 계좌번호, 금융회사 로그인 정보, 개인 소득·자산·신용점수를 입력받거나 수집하지 않습니다. 화면의 정책금리는 개인의 신용정보를 조회하거나 개인별 계약 금리를 산정한 결과가 아닙니다.

차트의 국가 선택·기간·표시 방식과 목록 필터는 화면 상태로 처리합니다. 이 선택을 계정별로 운영자 서버에 보관하는 기능은 제공하지 않습니다. 독립 iOS 구현에는 별도 운영자 행동 분석 전송이 연결되어 있지 않습니다. 광고 SDK 자체의 측정·진단 처리는 아래 안내와 구분됩니다.

2. 공개 자료 조회와 외부 연결

한국은행·미국 연준·일본은행의 정책금리를 운영자가 수집한 공개 자료 파일로 조회하며, 데이터 호스팅 서비스 Supabase에 연결합니다. 공개 자료 전체 파일을 읽으며 사용자의 계좌·소득·신용점수를 조회 조건으로 보내지 않습니다. 외부 링크를 선택하면 해당 기관의 사이트가 열리고 해당 기관의 정책이 적용됩니다.

3. Google AdMob 광고

독립 iOS 버전은 Google Mobile Ads와 User Messaging Platform(UMP)을 사용하는 공통 광고 구현을 적용합니다. 광고 요청은 비맞춤 광고(NPA)로 설정하고 게시자 자사 식별자와 개인정보 맞춤 설정을 비활성화합니다. 비맞춤 광고가 광고 사업자의 모든 수집이나 측정 처리가 없다는 뜻은 아닙니다.

Google Mobile Ads SDK는 IP 주소로 추정한 대략적 위치, 사용 가능한 기기·앱 식별자, 광고 노출·클릭·영상 등 상호작용, 앱 성능·충돌·진단 정보를 광고 제공·측정·부정사용 방지와 SDK 개선에 처리할 수 있습니다. 개인 계좌·소득·신용점수는 입력받지 않으며 광고 타기팅이나 광고 사용자 식별값으로 전송하지 않습니다.

4. ATT와 광고 개인정보 선택

iOS 추적 권한(ATT)은 다른 회사의 앱·웹사이트 간 추적과 광고 식별자 접근에 관한 시스템 선택입니다. 앱이 활성 상태이고 권한이 미결정일 때만 시스템 권한을 요청하며, 이미 허용·거부·제한된 상태에서 같은 팝업을 반복 요청하지 않습니다. iOS 설정에서 해당 앱의 추적 권한을 관리할 수 있습니다.

UMP의 지역별 광고 개인정보 선택은 ATT와 별개입니다. 추적을 거부하거나 제한된 상태라도 UMP가 광고 요청을 허용하면 비맞춤 배너를 요청할 수 있습니다. 미결정·비활성 상태나 권한·동의 확인 실패에는 광고를 요청하지 않습니다. 앱의 광고 동의 설정에서 제공 가능한 개인정보 선택을 확인하고, 기기 설정을 바꾼 뒤 복귀하면 현재 상태를 다시 확인합니다. 추적 허용은 금리 정보 이용의 조건이 아닙니다.
