공개 앱 안내 주소

출산 지원금의 지역별 참고 예시, 공개 자료를 참고해 재구성한 아기 이름 랭킹, 예방접종 참고 기준일과 완료 기록을 모은 가족용 도우미입니다. 지역과 출산 순위로 참고 정보를 살펴보고 연도·성별 이름을 탐색하며 아이의 생년월일에 달력의 개월·년을 더한 접종 참고 기준일과 완료 여부를 이 기기에 기록할 수 있습니다. 이름 랭킹은 공식 통계 원문이 아닌 근사 자료입니다. 실제 이전 접종일·제품·건강상태를 반영하는 예약이나 미접종 판정 기능은 아닙니다. 정부·의료기관의 공식 앱이 아닙니다.

추가 카드·번호 세트를 제공하는 앱 버전에서는 추가 카드·번호 세트도 광고 시청이나 추적 동의 없이 무료 생성 버튼으로 만들 수 있습니다. 별도의 광고 생성 버튼을 선택해도 같은 콘텐츠가 제공되며, 그 광고 경로는 실제 SDK 완료 확인 후에만 저장합니다. 광고 취소·실패를 완료로 취급하지 않으며 무료 생성 경로는 계속 이용할 수 있습니다.

출산 지원금은 참고용 예시 자료이며 이름 랭킹은 공식 통계 원문이 아닌 재구성 근사 자료입니다. 실제 지원 자격·금액은 담당 기관에 확인하세요. 접종 날짜는 생년월일에 달력의 개월·년을 더한 참고 기준일이며 실제 이전 접종일·제품·건강상태를 반영한 예약일이나 미접종 판정이 아닙니다. 실제 접종 시기는 의료진에게 확인하세요.

저장된 기록과 데이터

출산 지원금 조회의 지역·출산 순위 선택, 아이의 생년월일과 예방접종 완료 항목을 기기에 저장합니다. 생년월일 및 완료 기록을 운영자 데이터베이스에 전송하거나 저장하지 않습니다. 아기 이름 검색에는 아이의 실제 이름을 등록할 필요가 없습니다.

앱의 삭제·해제 기능이 제공되는 항목은 해당 화면에서 직접 지울 수 있습니다. 기기 안의 전체 앱 데이터를 지우려면 iOS 설정에서 앱을 삭제해 주세요. 앱 정리(Offload)는 앱 데이터가 남을 수 있습니다. 운영자는 기기 기록을 원격으로 복구할 수 없으며, iOS 백업은 본인의 기기·계정 설정에서 관리해 주세요.
